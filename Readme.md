<p>The project is upgraded by me using modern Sass <code>@use</code> and <code>@forward</code>.</p>

<p>I changed the SCSS postprocessor to <strong>Vite</strong></p>

## HOW TO RUN THE PROJECT

## REQUIREMENTS

NODEJS INSTALLED ON YOUR SYSTEM

### 1. Clone the repository

```bash
git clone https://github.com/raymanandrei/Sass-Trillo
cd Sass-Trillo
```

### 2. Run start command

```bash
npm run dev
```

### For building the project

```bash
npm run build
```

### To preview

```bash
npm run preview
```
